# backtester-btc

Backtester de stratégies de trading sur BTC/USDT, écrit en Python 3.14.

## Installation (Windows)

```
git clone https://github.com/BlumberMan/backtester-btc.git
cd backtester-btc
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python -m pytest -v
python -m backtester
```
